# المسلم V10

هذه النسخة توسّع قائمة القراء وتصحح مسار عبدالباسط إلى `ar.abdulbasit` مع جودة 192، وماهر المعيقلي إلى `ar.mahermuaiqly` مع جودة 128، وتستخدم معرفات Al Quran Cloud الموثقة عندما تكون متاحة، مع جلب بقية القراء من MP3Quran.

## اختبار سريع
1. افتح `index.html` عبر خادم محلي (وليس file:// إن أمكن).
2. جرّب الفاتحة مع ماهر المعيقلي وعبدالباسط.
3. جرّب قارئًا آخر وانتقل بين القراء للتأكد من عدم بقاء حالة التحميل القديمة.
4. بعد نجاح التشغيل ننتقل لتحسين تنزيل السور للاستخدام دون إنترنت.

> ملاحظة: توفر بعض القراء من MP3Quran يعتمد على بياناتهم الحالية، لذلك التطبيق يبحث عن المعرّف تلقائيًا بدل تخزين روابط ثابتة.
