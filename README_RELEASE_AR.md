# Quran M09alaroud V18

نسخة مرشحة للنشر كـPWA.

## ما تغير
- واجهة إسلامية فاخرة ومحسنة.
- بحث مباشر داخل قائمة القراء.
- إزالة مفضلة الشيوخ ومفضلة السور من الواجهة.
- الإبقاء على قسم المفضلة مع مفضلة الأحاديث والأذكار.
- الأحاديث تعرض المصدر والدرجة والتصنيف مع البحث والتصنيف.
- الأذكار تشمل عدة أقسام مع المصدر والعداد والمفضلة.
- Manifest + Service Worker لتجربة PWA.

## النشر على الويب
ارفع الملفات كلها إلى استضافة HTTPS، ولا تفتح index.html من file:// إذا أردت PWA/Service Worker.

## مهم قبل النشر العام
الحسابات الحقيقية ولوحة المالك تحتاج إعداد Supabase حقيقي وحماية خادمية. لا تضع مفاتيح سرية أو صلاحيات مالك داخل JavaScript في المتصفح.

## Google Play
هذه الملفات ليست APK/AAB. للنشر على Google Play يجب تحويل المشروع إلى تطبيق Android وبناء AAB مطابق لمتطلبات Play الحالية، ومنها استهداف Android 16 / API 36 أو أعلى للتطبيقات الجديدة اعتبارًا من 31 أغسطس 2026.
