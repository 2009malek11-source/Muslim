# المسلم V80.7 — أزرار المشاركة الصغيرة

## فتح الموقع
1. فك ضغط ملف ZIP كاملًا.
2. افتح المجلد `Muslim_V80_7_share_buttons`.
3. افتح `index.html` في المتصفح.

## أزرار المشاركة
- أضيف زر مشاركة صغيرًا (↗) بجانب كل سورة في صفحة كل قارئ.
- أضيف زر مشاركة صغيرًا بجانب زر حفظ QR في صفحة رمز QR.
- على الهواتف والمتصفحات الداعمة، يفتح زر المشاركة قائمة المشاركة المعتادة. إذا لم يدعم المتصفح المشاركة، يحاول نسخ الرابط إلى الحافظة أو يعرضه للنسخ اليدوي.

رابط الموقع المستخدم للمشاركة وQR:
https://2009malek11-source.github.io/Muslim/

ملاحظة: مشاركة رابط التلاوة المباشر تعتمد على توفر رابط الصوت لدى مصدر القارئ. إذا لم يتوفر، يشارك الزر رابط الموقع بدلًا منه.
